# Money Snap IA 화면 구조도

## 목적

이 문서는 Money Snap의 MVP 화면 구조를 간단히 정리한다.

현재 구조는 확정 스펙이 아니다. 실제 화면을 그리면서 탭 이름, 화면 수, 진입 방식은 바뀔 수 있다. 이 문서는 디자인을 시작하기 위한 가벼운 기준점으로 사용한다.

## 구조 원칙

- 홈은 오늘의 소비 캔버스다.
- 기록하기는 어디서든 빠르게 시작할 수 있어야 한다.
- 그룹 공유는 별도 복잡한 SNS 구조가 아니라 그룹 단위 화면으로 둔다.
- 홈에서는 나의 Snap과 그룹 Snap을 스와이프로 빠르게 볼 수 있다.
- 그룹 탭은 그룹 목록, 그룹 생성/초대, 특정 그룹 Snap 진입을 담당한다.
- 수정/삭제는 홈 하단 소비 목록에서 Snap 상세로 진입해 처리한다.
- 화면 수는 최소화하고, 세부 설정 화면은 MVP에서 최대한 줄인다.

## 하단 탭 초안

```text
홈
그룹
추가
보관함
마이
```

### 로그인

session이 없거나 복구할 수 없을 때만 표시하는 진입 화면이다.

- Sign in with Apple 단일 액션
- 로그인 진행·실패·재시도 상태
- 유효한 session이 있으면 표시하지 않음

### 홈

오늘의 소비 캔버스를 보는 메인 화면이다.

- 오늘의 소비 캔버스
- 그룹 Snap 스와이프 보기
- 기록하기 진입
- 오늘 소비 목록
- Snap 상세 진입

### 그룹

친구와 함께 공유한 소비를 보는 화면이다.

- 내가 속한 그룹 목록
- 그룹별 오늘 Snap 진입
- 그룹 생성/초대 진입
- 그룹별 금액 공개 설정 확인

### 추가

소비 기록을 바로 시작하는 진입점이다.

- 사진 촬영
- 앨범 선택
- 사진 없음
- 선택한 사진 미리보기와 진행 표시
- 카테고리 선택 바텀시트
- 가격 입력 바텀시트
- 여러 장 선택 시 다음 사진 자동 진행
- 저장 완료 후 홈 캔버스 반영

### 보관함

지난 소비 스냅을 날짜별로 돌아보는 화면이다.

- 날짜별 소비 캔버스
- 지난 기록 보기

### Snap 상세

저장된 소비를 확인하고 최소한의 수정만 처리하는 화면이다.

- 소비 이미지 또는 기본 오브젝트 확인
- 카테고리 수정
- 가격 수정
- 삭제
- 공유 그룹 변경은 제공하지 않음

### 마이

내 정보와 기본 설정을 관리하는 화면이다.

- 프로필
- 내 그룹 관리
- 앱 설정
- 로그아웃
- 계정 탈퇴와 재인증 확인
- 알림 설정은 MVP에서 제공하지 않음

## 주요 화면 연결

```text
홈
├─ 기록하기 → 추가
├─ 좌우 스와이프 → 그룹 Snap 빠른 보기
├─ 오늘 소비 목록 → Snap 상세
└─ 공유 미리보기

추가
├─ 사진 촬영
├─ 앨범 선택, 한 장 또는 여러 장
├─ 사진 없음
├─ 카테고리 선택 바텀시트, 현재 사진 미리보기
└─ 가격 입력 바텀시트 → 현재 사진 저장 → 남은 사진이 있으면 반복

그룹
├─ 그룹 목록
├─ 그룹 상세 Snap
├─ 그룹 생성/초대
└─ 그룹 금액 공개 설정 확인

보관함
└─ 날짜별 소비 스냅 → Snap 상세

마이
├─ 프로필
├─ 그룹 관리
└─ 설정 → 로그아웃 / 계정 탈퇴
```

## 그룹 상세 Snap 구조

그룹 상세 Snap은 그룹 전체 소비 금액이나 개별 Snap 리스트를 크게 보여주는 화면이 아니다. 이 화면은 친구들이 오늘 공유한 소비 흐름을 사람별 대표 Snap으로 훑어보는 공간이다.

- 사람별 대표 Snap 캔버스
- 유저별 최신 소비 이미지
- 유저별 프로필 이미지, 미등록 시 기본 이니셜 프로필
- 유저별 이름과 오늘 Snap 개수, 하단 정보 태그 안에 표시
- 유저별 오늘 총액, 금액 공개 그룹인 경우
- 금액 비공개 표시, 금액 비공개 그룹인 경우
- 유저별 오늘 Snap 상세 진입 화살표
- 오늘 기록한 인원과 Snap 개수
- 공개 그룹에서는 유저별 총액 기준으로 오브젝트 크기를 다르게 표시
- 비공개 그룹에서는 총액 기준 크기 차이를 사용하지 않음
- 우상단 Snap 개수 배지는 사용하지 않음
- 그룹 상세 하단에는 별도 개별 Snap 리스트를 두지 않음

## MVP 우선 화면

MVP에서 먼저 설계할 화면은 다음 순서로 본다. 현재 디자인은 한 화면씩 만들고 피드백을 반영하면서 조정한다.

1. 홈
2. 그룹
3. 그룹 상세 Snap
4. 추가
5. Snap 상세
6. 저장 이후 그룹 공유 흐름
7. 보관함
8. 마이와 계정 관리

## 보류할 판단

다음 항목은 실제 화면을 그리면서 조정한다.

- 추가를 하단 탭으로 둘지, 홈의 큰 액션 버튼으로 둘지
- 저장 이후 그룹 공유를 어느 화면에서 제안할지
- 공유 미리보기를 홈 안에 둘지, 별도 화면으로 둘지
- 보관함과 마이를 MVP 첫 버전에 얼마나 가볍게 둘지
