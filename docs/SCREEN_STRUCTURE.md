# Money Snap IA 화면 구조도

## 목적

이 문서는 Money Snap의 MVP 화면 구조를 간단히 정리한다.

현재 구조는 확정 스펙이 아니다. 실제 화면을 그리면서 탭 이름, 화면 수, 진입 방식은 바뀔 수 있다. 이 문서는 디자인을 시작하기 위한 가벼운 기준점으로 사용한다.

## 구조 원칙

- 홈은 오늘의 소비 캔버스다.
- 기록하기는 어디서든 빠르게 시작할 수 있어야 한다.
- 그룹 공유는 별도 복잡한 SNS 구조가 아니라 그룹 단위 화면으로 둔다.
- 수정/삭제는 홈 하단 소비 목록에서 접근한다.
- 화면 수는 최소화하고, 세부 설정 화면은 MVP에서 최대한 줄인다.

## 하단 탭 초안

```text
홈
그룹
추가
보관함
마이
```

### 홈

오늘의 소비 캔버스를 보는 메인 화면이다.

- 오늘의 소비 캔버스
- 기록하기 진입
- 오늘 소비 목록
- 소비 수정/삭제 진입

### 그룹

친구와 함께 공유한 소비를 보는 화면이다.

- 내가 속한 그룹 목록
- 그룹별 공유 소비
- 그룹 생성/초대 진입

### 추가

소비 기록을 바로 시작하는 진입점이다.

- 사진 촬영
- 앨범 선택
- 가격 입력
- 카테고리 선택
- 그룹 선택, 그룹이 있는 경우

### 보관함

지난 소비 스냅을 날짜별로 돌아보는 화면이다.

- 날짜별 소비 캔버스
- 지난 기록 보기

### 마이

내 정보와 기본 설정을 관리하는 화면이다.

- 프로필
- 내 그룹 관리
- 기본 공개 설정
- 앱 설정

## 주요 화면 연결

```text
홈
├─ 기록하기 → 추가
├─ 오늘 소비 목록 → 소비 상세/수정
└─ 공유 미리보기

추가
├─ 사진 촬영
├─ 앨범 선택
├─ 가격 입력
├─ 카테고리 선택
└─ 그룹 선택

그룹
├─ 그룹 목록
├─ 그룹 상세
└─ 그룹 생성/초대

보관함
└─ 날짜별 소비 스냅

마이
├─ 프로필
├─ 그룹 관리
└─ 설정
```

## MVP 우선 화면

MVP에서 먼저 설계할 화면은 다음 순서로 본다.

1. 홈
2. 추가
3. 그룹 선택
4. 그룹
5. 소비 상세/수정
6. 보관함
7. 마이

## 보류할 판단

다음 항목은 실제 화면을 그리면서 조정한다.

- 추가를 하단 탭으로 둘지, 홈의 큰 액션 버튼으로 둘지
- 그룹 선택을 전체 화면으로 둘지, 바텀시트로 둘지
- 공유 미리보기를 홈 안에 둘지, 별도 화면으로 둘지
- 보관함과 마이를 MVP 첫 버전에 얼마나 가볍게 둘지
