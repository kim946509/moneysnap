# Money Snap IA 화면 구조도

## 목적

이 문서는 Money Snap의 MVP 화면 구조를 간단히 정리한다.

현재 구조는 확정 스펙이 아니다. 실제 화면을 그리면서 탭 이름, 화면 수, 진입 방식은 바뀔 수 있다. 이 문서는 디자인을 시작하기 위한 가벼운 기준점으로 사용한다.

## 구조 원칙

- 홈은 오늘의 소비 캔버스다.
- 기록하기는 어디서든 빠르게 시작할 수 있어야 한다.
- 그룹 공유는 별도 복잡한 SNS 구조가 아니라 그룹 단위 화면으로 둔다.
- 홈에서는 나의 Snap과 그룹 Snap을 스와이프로 빠르게 볼 수 있다.
- 그룹 탭은 그룹 목록, 그룹 생성/초대, 특정 그룹 Snap 진입을 담당한다.
- 수정/삭제는 홈 하단 소비 목록에서 Snap 상세로 진입해 처리한다.
- 화면 수는 최소화하고, 세부 설정 화면은 MVP에서 최대한 줄인다.

## 하단 탭 초안

```text
홈
그룹
추가
보관함
마이
```

### 로그인

session이 없거나 복구할 수 없을 때만 표시하는 진입 화면이다.

- Sign in with Apple 단일 액션
- 로그인 진행·실패·재시도 상태
- 유효한 session이 있으면 표시하지 않음

### 홈

오늘의 소비 캔버스를 보는 메인 화면이다.

- 오늘의 소비 캔버스. 기록이 없어도 같은 chrome과 `오늘 총 소비 ₩0`을 유지한다
- 오른쪽 메뉴 버튼으로 사이드바 열기
- 그룹 Snap 스와이프 보기
- 기록하기 진입
- 오늘 소비 목록
- Snap 상세 진입
- 저장된 Snap의 비차단 공유 action, 속한 그룹이 있을 때만 표시

### 그룹

친구와 함께 공유한 소비를 보는 화면이다.

- 내가 속한 그룹 목록
- 그룹별 오늘 Snap 진입
- 그룹 생성, trim 후 1~30 grapheme cluster 이름과 생성 시 고정되는 금액 공개 설정
- 168시간 단일 active 초대 발급·재발급
- 가입 전 group name·금액 공개 preview
- owner/member 관리, owner 포함 최대 20명

### 추가

소비 기록을 바로 시작하는 진입점이다.

- 카메라 뷰파인더(셔터·앨범·없음)
- 앨범 선택
- 사진 없음
- 선택한 사진 미리보기와 진행 표시
- 사진 시작은 카메라 구성, 카테고리와 금액은 넓은 시트에서 함께 입력
- 여러 장 선택 시 다음 사진 자동 진행
- 저장 완료 후 홈 캔버스 반영
- 한 사진마다 별도 Snap 순차 저장, Snap당 active image 최대 1개

### 보관함

지난 소비 스냅을 날짜별로 돌아보는 화면이다.

- `Archive` 타이틀과 월 달력
- 기록이 있는 날짜 marker와 선택 날짜
- 선택한 날의 개인 Snap 목록과 총액
- Snap 상세 진입

### Snap 상세

저장된 소비를 확인하고 최소한의 수정만 처리하는 화면이다.

- 소비 이미지 또는 기본 오브젝트 확인
- 카테고리 수정
- 가격 수정
- 삭제
- 공유 그룹 변경은 제공하지 않음

### 마이

내 정보와 기본 설정을 관리하는 화면이다.

- 프로필
- 내 그룹 관리
- 앱 설정
- 도움말
- 로그아웃
- 계정 탈퇴와 재인증 확인
- 알림 설정은 MVP에서 제공하지 않음
- 이름 편집과 profile 사진 업로드는 MVP에서 제공하지 않으며 기본값은 `MoneySnap 사용자`와 첫 grapheme/MoneySnap mark

## 주요 화면 연결

```text
홈
├─ 기록하기 → 추가
├─ 좌우 스와이프 → 그룹 Snap 빠른 보기
├─ 오늘 소비 목록 → Snap 상세
└─ 저장된 Snap 공유 action → 단일 group 선택 sheet

추가
├─ 사진 촬영
├─ 앨범 선택, 한 장 또는 여러 장
├─ 사진 없음
└─ 카테고리와 금액을 함께 입력하는 넓은 시트 → 현재 사진 저장 → 남은 사진이 있으면 반복

그룹
├─ 그룹 목록
├─ 그룹 상세 Snap
├─ 그룹 생성 → 이름 / 생성 시 고정 금액 공개 설정
├─ 초대 발급 / 가입 preview
└─ member 탈퇴 / owner member 제거·그룹 삭제

보관함
└─ 날짜별 소비 스냅 → Snap 상세

마이
├─ 프로필
├─ 그룹 관리
└─ 설정 → 로그아웃 / 계정 탈퇴
```

## 그룹 상세 Snap 구조

그룹 상세 Snap은 그룹 전체 소비 금액이나 개별 Snap 리스트를 크게 보여주는 화면이 아니다. 이 화면은 친구들이 오늘 공유한 소비 흐름을 사람별 대표 Snap으로 훑어보는 공간이다.

- 사람별 대표 Snap 캔버스
- 유저별 `sharedAt` 기준 최신 소비 이미지, 사진이 없으면 category별 고정 icon/color placeholder
- 유저별 기본 avatar, display name 첫 grapheme 또는 MoneySnap mark
- 유저별 이름과 오늘 Snap 개수, 하단 정보 태그 안에 표시
- 유저별 오늘 총액, 금액 공개 그룹인 경우
- 금액 비공개 표시, 금액 비공개 그룹인 경우
- 유저별 오늘 Snap 상세 진입 화살표
- 오늘 기록한 인원과 Snap 개수
- 공개 그룹에서는 유저별 총액 기준으로 오브젝트 크기를 다르게 표시
- 비공개 그룹에서는 총액 기준 크기 차이를 사용하지 않음
- 우상단 Snap 개수 배지는 사용하지 않음
- 그룹 상세 하단에는 별도 개별 Snap 리스트를 두지 않음

## MVP 우선 화면

MVP에서 먼저 설계할 화면은 다음 순서로 본다. 현재 디자인은 한 화면씩 만들고 피드백을 반영하면서 조정한다.

1. 홈
2. 그룹
3. 그룹 상세 Snap
4. 추가
5. Snap 상세
6. 저장 이후 그룹 공유 흐름
7. 보관함
8. 마이와 계정 관리

## 후속 시각 판단

정책상 공유 진입은 저장된 Snap의 Home action, 대상 선택은 한 번에 group 하나로 확정됐다. 다음 항목은 그 정책을 바꾸지 않는 범위에서 실제 Figma 화면을 그리며 조정한다.

- 추가 진입을 하단 중앙 action과 Home의 큰 action에 어떻게 일관되게 표현할지
- Home share action과 단일 group 선택 sheet의 정확한 배치
- 보관함과 마이의 정보 밀도
