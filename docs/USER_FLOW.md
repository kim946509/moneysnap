# Money Snap 핵심 사용자 흐름

## 목적

이 문서는 Money Snap의 핵심 사용자 흐름을 정의한다. 시각 디자인의 세부 스타일을 정하는 문서가 아니라, 사용자가 앱을 어떻게 시작하고, 소비를 어떻게 기록하며, 언제 개인 기록과 그룹 공유를 선택하는지 정하는 기준 문서다.

UI/UX 관점은 이 단계부터 고려한다. 단, 여기서 결정할 것은 색상, 폰트, 카드 모양 같은 시각 상세가 아니라 **사용자가 어느 순간에 고민하고, 어느 순간에 바로 끝낼 수 있어야 하는가**이다.

## 흐름 원칙

- 홈은 오늘의 소비 캔버스다.
- 사용자는 홈에서 바로 소비를 기록할 수 있어야 한다.
- 기록은 사진을 먼저 선택하고, 금액과 카테고리를 입력하는 짧은 흐름이어야 한다.
- 소비는 저장 즉시 오늘의 소비 캔버스에 반영되어야 한다.
- 기본 저장 위치는 항상 나만 보기다.
- 그룹 공유는 사용자가 속한 그룹이 있을 때만 기록 흐름 안에 가볍게 등장한다.
- 그룹 선택 단계가 있더라도 사용자가 공유를 고민하느라 기록을 포기하게 만들면 안 된다.

## 핵심 루프

Money Snap의 메인 루프는 다음과 같다.

1. 사용자는 홈에서 오늘의 소비 캔버스를 본다.
2. 사용자는 기록하기를 눌러 소비 사진을 촬영하거나 앨범에서 선택한다.
3. 사용자는 금액과 카테고리를 입력한다.
4. 사용자가 속한 그룹이 없다면 소비는 바로 나만 보기로 저장된다.
5. 사용자가 속한 그룹이 있다면 그룹 선택 단계가 나타난다.
6. 사용자는 나만 보기로 저장하거나, 특정 그룹에도 함께 저장한다.
7. 저장된 소비는 즉시 오늘의 소비 캔버스에 시각적으로 반영된다.
8. 사용자는 캔버스를 보며 오늘의 소비 흐름을 직관적으로 이해한다.

## 기본 홈 흐름

홈은 리스트나 통계 화면이 아니라 오늘의 소비 캔버스다.

홈에서 사용자는 오늘 기록한 소비를 사진, 크기, 배치 중심으로 본다. 많이 쓴 소비는 더 크게 보이고, 적게 쓴 소비는 더 작게 보인다. 사용자는 숫자표를 읽지 않아도 오늘 어디에 돈이 크게 나갔는지 바로 이해할 수 있어야 한다.

홈의 핵심 행동은 기록하기다. 기록하기는 홈에서 가장 쉽게 접근할 수 있어야 하며, 사용자가 소비를 떠올린 순간 바로 시작할 수 있어야 한다.

## 소비 기록 흐름

### 1. 사진 선택

사용자는 기록하기를 누른 뒤 사진을 촬영하거나 앨범에서 이미지를 선택한다.

사진 선택은 소비 기록의 시작점이다. Money Snap은 숫자 입력으로 시작하는 가계부가 아니라, 오늘의 소비 장면을 먼저 남기는 앱이어야 한다.

### 2. 금액 입력

사진을 선택한 뒤 사용자는 금액을 입력한다.

금액 입력은 빠르고 단순해야 한다. 이 단계에서 예산, 결제수단, 상세 메모 같은 추가 입력을 요구하지 않는다.

### 3. 카테고리 선택

금액 입력 후 사용자는 카테고리를 선택한다.

카테고리는 소비를 이해하기 위한 최소 분류다. 카테고리 선택은 기록 흐름을 방해하지 않을 만큼 단순해야 하며, 추후 캔버스 표현과 공유 카드의 분위기를 결정하는 데 사용된다.

### 4. 저장 또는 그룹 선택

사용자가 속한 그룹이 없다면 카테고리 선택 후 바로 저장된다.

사용자가 속한 그룹이 있다면 카테고리 선택 후 그룹 선택 단계가 추가된다. 이 단계의 기본 선택은 나만 보기다. 사용자는 원할 때만 하나 이상의 그룹을 선택해 함께 저장한다.

그룹 선택 단계는 공유를 강요하는 화면이 아니라, "이 소비를 어디에 함께 남길까?"를 가볍게 묻는 화면이어야 한다.

### 5. 캔버스 반영

저장이 완료되면 사용자는 홈으로 돌아가고, 새 소비가 오늘의 소비 캔버스에 바로 나타난다.

이 즉시 반영이 기록의 보상이다. 사용자는 입력을 끝낸 직후 자신의 소비 캔버스가 변하는 것을 보며 기록의 재미를 느껴야 한다.

## 그룹이 없는 사용자 흐름

```text
홈 캔버스
→ 기록하기
→ 사진 촬영 또는 앨범 선택
→ 금액 입력
→ 카테고리 선택
→ 자동 저장
→ 홈 캔버스에 즉시 반영
```

이 흐름은 Money Snap의 가장 가벼운 기본 경험이다. 사용자는 공유나 그룹을 몰라도 혼자서 충분히 앱을 사용할 수 있어야 한다.

## 그룹이 있는 사용자 흐름

```text
홈 캔버스
→ 기록하기
→ 사진 촬영 또는 앨범 선택
→ 금액 입력
→ 카테고리 선택
→ 그룹 선택
→ 나만 보기 또는 그룹 함께 저장
→ 홈 캔버스에 즉시 반영
```

그룹이 있는 사용자에게도 기본값은 나만 보기다. 그룹 선택은 공유를 열어두는 단계이지, 공유를 필수로 만드는 단계가 아니다.

## 홈 캔버스의 역할

홈 캔버스는 Money Snap의 정체성을 보여주는 첫 화면이다.

참고 방향은 Kit iOS 레퍼런스처럼 넓은 여백, 큰 시각 오브젝트, 장난기 있는 위젯형 구성, 하단 탭 기반 모바일 앱 감각이다. 단, Money Snap에서는 금융 관리 화면처럼 딱딱해지지 않도록 사진 기반 소비 오브젝트와 크기 차이를 핵심 시각 언어로 삼는다.

홈 캔버스는 다음 역할을 한다.

- 오늘의 소비를 한눈에 보여준다.
- 기록이 끝난 직후 변화가 보이는 보상 화면이 된다.
- 공유용 스냅샷의 원본이 된다.
- 사용자가 매일 돌아오는 메인 루프의 시작점이 된다.

## UX 판단 기준

- 기록 흐름은 사용자가 10초 안에 완료할 수 있어야 한다.
- 그룹이 없는 사용자는 공유 단계를 보지 않아야 한다.
- 그룹이 있는 사용자도 나만 보기 저장을 쉽게 끝낼 수 있어야 한다.
- 저장 완료 후 캔버스 반영은 즉각적이어야 한다.
- 소비 기록은 가계부 작성보다 사진 스냅 저장에 가까워야 한다.
- 공유는 흐름의 중심이지만 기록보다 앞서 사용자를 멈추게 하면 안 된다.

## 다음에 정의할 것

이 문서는 핵심 흐름만 정의한다. 다음 항목은 후속 기획 단계에서 별도로 정한다.

- 그룹 선택 화면의 세부 정책
- 그룹별 금액 공개 옵션
- 그룹에 공유된 소비가 친구에게 보이는 방식
- 저장 완료 후 공유 제안 방식
- 오늘의 소비 캔버스 자동 배치 규칙
- 하단 탭 구조와 화면별 진입 방식
